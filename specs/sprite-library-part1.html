/* Each sprite is a self-contained <svg> element.
   Embed directly in HTML. Scale with width/height attributes.
   Key techniques used:
   1. linearGradient / radialGradient in <defs> for shading
   2. <polygon> and <path> for armor plates and complex shapes
   3. <filter> with feGaussianBlur + feMerge for glow effects
   4. Layering order: shadow → feet → legs → body → arms → weapons → head
   5. Highlight ellipses (white, low opacity) for metallic sheen
*/
