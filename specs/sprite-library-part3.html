7. QUALITY STANDARDS & BENCHMARK

Quality levels for HoMM3-style games. Minimum acceptable: Level 3. Target: Level 4-5.
LevelDescriptionSVG ElementsKey DifferentiatorsVerdict
1 Primitive shape 3-8 elements Circle + rect, no detail UNACCEPTABLE — prototype only
2 Stick figure / blob 8-15 elements Basic limbs, no gradients TOO SIMPLE — looks like a placeholder
3 Recognizable character 15-30 elements Gradients, distinct silhouette, 2-3 colors MINIMUM ACCEPTABLE — playable
4 Detailed character 30-60 elements Armor detail, gradients, shadow, weapon, face GOOD — looks intentional, game-ready
5 HoMM3-quality 60-100+ elements Scale/fur texture, glow effects, plume/mane, facial expression EXCELLENT — matches HoMM3 aesthetic

Minimum Requirements Checklist

EVERY unit sprite MUST have:
[ ] Distinct silhouette — recognizable from thumbnail
[ ] At least 2 gradients (body shading + highlight)
[ ] Shadow ellipse beneath unit
[ ] Face/eyes (even if simple)
[ ] Weapon or distinctive feature
[ ] Faction-appropriate color palette

QUALITY UNITS also include:
[ ] feGaussianBlur glow on magical/fire elements
[ ] Texture lines (fur, scales, armor ridges)
[ ] Highlight ellipses on metal (white, 0.1-0.2 opacity)
[ ] Proper layering: shadow > feet > legs > body > arms > head
[ ] Readable at 60x80px AND 120x160px

Complete Sprite Build Guide (Step by Step)

/* HOW TO BUILD A HIGH-QUALITY SVG SPRITE FROM SCRATCH */

STEP 1: Define gradients in <defs>
  - Primary material gradient (steel/leather/scales/skin)
  - Highlight gradient (lighter version, for lit surfaces)
  - Eye/glow radialGradient
  - Any magical effect gradient

STEP 2: Draw shadow
  <ellipse cx="CX" cy="BOTTOM" rx="14" ry="4" fill="#000" opacity="0.35"/>

STEP 3: Draw ground-contact parts first (boots, hooves, paws)
  Use filled rects/paths, add darker bottom edge

STEP 4: Draw legs (rect with rx for roundness)
  Two rectangles + knee ellipses for articulation

STEP 5: Draw hips/pelvis
  Polygon or path connecting the legs to torso

STEP 6: Draw torso/chest
  Wide rect or ellipse, apply primary gradient
  Add center-line ridge (line element)
  Add highlight ellipse at upper-left (white, opacity 0.1-0.15)

STEP 7: Draw arms
  Upper arm rect + elbow ellipse + forearm rect
  Apply same gradient as torso

STEP 8: Draw shoulder pads/pauldrons
  Ellipses over shoulder joints, slightly larger than arm width

STEP 9: Draw weapon (right hand) or shield (left hand)
  Sword: rect (grip) + thin polygon (blade) + rect (crossguard)
  Shield: polygon with gradient + rim line + boss circle
  Staff: thin rect + ornamental top + orb circle with glow

STEP 10: Draw neck and head
  Neck: small rect
  Head: ellipse, slightly wider than neck
  For helmets: helmet ellipse covers hair, add visor path

STEP 11: Add face/helmet details
  Visor slots: small dark rects
  Helmet plume: curved path lines
  Eyes (if visible): white ellipse + colored iris circle + dark pupil + white specular dot

STEP 12: Add final polish
  Glow filters for magical elements
  Scale texture: repeated curved path strokes
  Fur texture: short curved stroke lines

SIZING REFERENCE:
  Infantry unit:  60x80px viewBox, display at 80x110
  Cavalry unit:  100x80px viewBox, display at 130x110
  Dragon/large:  140x100px viewBox, display at 160x120
  Building:      80x120px viewBox
  Terrain tile:  64x64px or 80x80px
